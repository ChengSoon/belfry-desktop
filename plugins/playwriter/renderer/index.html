首次使用

  1. 安装浏览器扩展

    在你平时使用、已经登录网站的 Chrome 中安装 Playwriter 官方扩展。

  2. 连接一个网页

    打开需要操作的普通网页，点击浏览器工具栏中的 Playwriter 图标；图标变绿表示已连接。

  3. 验证后，直接给 Agent 下任务

    连接测试会临时打开一个测试页，验证输入和点击，完成后自动关闭。

试着对 Agent 说

“用浏览器助手读取我刚打开的网页，整理主要内容。”

停用插件可释放连接；点击浏览器扩展图标可断开网页。
