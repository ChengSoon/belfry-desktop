# Review Kit 目录插件

普通安装：设置 → 插件 → 安装插件包，选择同级的 `review-directory.piplug`。
也可选择“安装目录插件”导入本目录。核对预览后安装，再点击启用。
命令和 Skill 在插件中心可查看和复制；设置贡献展示默认值。
示例独立提供 commands、skills、settings 三类静态贡献，无需安装其他插件或运行环境。
P0 不执行第三方 JS；可执行命令与自定义面板属于后续阶段。

开发加载保留源目录；修改内容后重载。更改身份或权限必须卸载、重新预览安装。
旧单文件 .belfry-plugin.json 示例属于此前 Prompt/Recipe 原型，不适用于新宿主。
