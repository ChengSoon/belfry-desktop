# 外观

## 主题

**亮 / 暗主题切换**，主题色会**同步喂给终端调色板**——界面和终端的颜色始终协调，不会出现亮色界面配暗色终端的割裂感。

## 字体

- 全应用字体与 **`10–20px` 字号**同步自定义
- 支持**本机已安装的字体**
- 可导入多个字体文件：**TTF / OTF / WOFF / WOFF2**，分别切换或删除
- 随时可以**切回系统字体**

## 内置字体

Belfry 自带两套字体：

- **JetBrains Mono**（等宽，用于终端与代码，SIL OFL 1.1）
- **HarmonyOS Sans SC**（中文字体）

各自遵循自己的许可，详见仓库 `LICENSE` 目录。
