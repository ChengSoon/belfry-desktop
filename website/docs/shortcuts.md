# 快捷键

macOS 用 `⌘`，Windows 用 `Ctrl+Shift` 组合。

:::note 为什么 Windows 是 Ctrl+Shift
**特意避开 `Ctrl` 单键组合**，因为要给 Codex 与 Claude 的原生 CLI 快捷键让路——它们在终端里会吃掉 `Ctrl` 按键，宿主不能再占用。
:::

| 功能 | macOS | Windows |
| --- | --- | --- |
| 新建 Shell | `⌘T` | `Ctrl+Shift+T` |
| 折叠 / 展开侧栏 | `⌘B` | `Ctrl+Shift+B` |
| Quick Open | `⌘K` | `Ctrl+Shift+K` |
| 开关用量面板 | `⌘U` | `Ctrl+Shift+U` |
| 开关历史 | `⌘⇧H` | `Ctrl+Shift+H` |
| 打开设置 | `⌘,` | `Ctrl+Shift+,` |
| 切换会话 | `⌘1` – `⌘9` | `Ctrl+Shift+1` – `Ctrl+Shift+9` |
| 打开快捷指令 | `⌘/` | `Ctrl+Shift+/` |
| 搜索终端内容 | `⌘F` | `Ctrl+Shift+F` |

## 终端内的快捷键

这些是终端内容操作，不走会话管理：

- **`⌘F`** 搜索当前终端内容，支持跨换行匹配
- 点击终端里的 **HTTP(S) 地址** 直接打开
- 点击终端里的**文件路径**跳转到文件预览窗格
