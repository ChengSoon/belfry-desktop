# 工作区

## 项目

**项目就是一个本地目录。** 点击顶部的项目选择器打开一个目录，会话都挂在它下面。

- 最近打开过的项目会被记住，下次直接选
- **不同会话可以指向不同目录**：会话自带项目归属，不是全局单一的
- 侧栏按项目分组，可折叠，宽度可拖拽

## 会话与分屏

一个项目下可以开任意多个会话。**拖拽标签即可分屏**，布局自己定。

常见的玩法：

| 组合 | 适合场景 |
| --- | --- |
| Codex + Shell | 一边让 Agent 改代码，一边自己看日志、跑测试 |
| 两个 Codex | 分工配合，见[会话协作](./collab.md) |
| SSH + Shell | 连着远程服务器，同时本地操作 |
| 纯 Shell | 当普通终端用 |

## 命名工作区

分屏布局开好后，可以存成**命名工作区**。它会保留：

- 会话分组
- 分屏布局
- 活动焦点

重新打开命名工作区时，**后台会话的身份也会恢复**——不用重新登录、重新 `cd`。

## Quick Open

按 `⌘K`（Windows `Ctrl+Shift+K`）打开 Quick Open，可以：

- 搜索并切换会话
- 打开最近的项目
- 执行常用工作区动作

支持键盘导航，手不离开键盘就能完成跳转。

## 文件预览窗格

文件预览窗格可以浏览当前项目目录、打开**只读**代码预览。两个顺手的能力：

- **终端输出里的文件路径可直接点击跳转**，在预览窗格里打开
- 文件在磁盘上被外部改动时，预览会提示你磁盘变更

:::caution 只读
预览窗格是只读的，不能直接改文件。要改文件请用你的编辑器，或让 Agent 改。
:::

## 收起侧栏

按 `⌘B`（Windows `Ctrl+Shift+B`）整体收起侧栏，把空间全让给终端。
