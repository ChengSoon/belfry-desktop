# Appearance

## Themes

Switch between **light and dark themes**. The theme color is **fed into the terminal palette as well** — the interface and terminal always stay in harmony, never a light interface paired with a dark terminal.

## Fonts

- The app-wide font and a **synchronized `10–20px` font size**
- Support for **fonts already installed on your machine**
- Import multiple font files: **TTF / OTF / WOFF / WOFF2**, and switch between or delete them individually
- You can always **switch back to the system font**

## Bundled fonts

Belfry ships with two fonts:

- **JetBrains Mono** (monospace, for the terminal and code, SIL OFL 1.1)
- **HarmonyOS Sans SC** (Chinese typeface)

Each follows its own license — see the `LICENSE` files in the repository.
