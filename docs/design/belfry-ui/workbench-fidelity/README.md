# 主工作台按 B 曜石稿还原（T15）

用户反馈 T7 之后的工作台「只换了颜色，和最初设计稿完全不一样」。本批以 `../directions/workbench.html?dir=b` 为准，把工作台的结构和细节还原到生产代码里。

## 怎么看

| 入口 | 内容 |
| --- | --- |
| `index.html` | 设计稿（左）和实装（右）并排：暗、亮各 1440 宽，另附 Windows 1440 和 720×480 窄窗 |
| `after/{macos,windows}/` | 本批构建用 `capture-ui-baseline.mjs` 拍的 36 张图和 manifest |
| `vs-t7/{macos,windows}/index.html` | 和 T7（`batch-2/after`）的逐像素对比 |

两边截图里的数据不同：设计稿是演示数据，实装截图是测试夹具的合成数据（超长项目名、两个 Shell 会话），所以文字内容不同是正常的，对照的是结构、尺寸和层级。

### 没有照搬的部分

- **右侧元信息**（模型名、上下文用量、「统计」）：现有数据模型里没有每个会话的模型和上下文用量，为了凑出这一栏去编数据不合适，所以没做。以后 Agent 状态里有了这些字段，可以加在状态条右侧。
- **顶栏的「+ 新标签」和分屏按钮**：新建会话在侧栏的「+」里（菜单里有 Agent / Shell / SSH 三种），分屏靠把会话拖到终端上。这两项保持现状，没有新增入口，以免同一件事有两种做法。
- **设计稿里给 Claude Code 图标块用的橙色**：照搬了。这是 B 稿里唯一的品牌色点缀，其他 Agent 的图标块用中性色。

## 保留不变的行为

- 会话行仍然是 `.session-row__main` 按钮，点击切换、双击或 F2 改名、按住拖动分屏、Escape 和输入法回车的守卫都没变；关闭、改名、SSH 编辑按钮仍在行尾，悬停时出现。
- 侧栏折叠、宽度拖拽、项目组折叠动画、拖回侧栏移出分屏都不受影响。`motion.case.mjs` 和 `perf-interactions.case.mjs` 全部通过。
- 终端挂载（TerminalStage 和 PTY）没动。用户的字体、字号、壁纸偏好原样保留，`production-ui` 里壁纸和排版的用例通过。
- 「快速打开」的快捷键、`⌘K` 的提示文字、顶栏的 `aria-label="Quick Open"` 都保留了。

### 关于 `sidebar-layout.case.mjs`

改代码之前，我先用 **T7 原版构建**（`/tmp/belfry-ui-t7-dist-C1gJpsbW`，没有 T15 改动）跑了这个用例：两项**本来就失败**，`expected 0, actual 8`。原因是 T7 把主区改成了内缩 8px 的浮起面，而这个用例还在断言主区贴着窗口顶边（`y == 0`），高度等于整个窗口。也就是说，这是 T7 留下的过期断言，不是 T15 造成的回归。我按曜石的布局契约改了断言：主区四周的内缩等于 `--content-inset`（8px），上沿可以因为 macOS 交通灯让位而更大，收起侧栏时左侧也保留 8px。侧栏铺满整个高度、工具栏贴底、列表不会把工具挤出屏幕，这几条原有断言都保留了。

## 遗留

- 设置页、房间页在 macOS 顶部 28px 的色阶问题（T9 发现）不在本批，按计划在 T12、T14 处理。
- 同项目会话超过 6 个时，多出来的标签不显示（当前会话一定显示）。现在没有「更多」溢出菜单，完整列表在侧栏。
- 真机（WKWebView / WebView2）的观感还需要目测，尤其是 Windows 下 `Ctrl+Shift+K` 这种较长的快捷键提示在窄侧栏里会不会被截断。截图里 720 宽下显示正常。
