# Belfry 视觉方向稿（T3）

打开 `index.html` 可以并排对比三个方向的亮色和暗色版本。单页地址是 `workbench.html?dir=a|b|c&theme=dark|light`，`shots/` 目录下有 1440×900 截图。全部内容只依赖本地字体和资产，终端输出和会话都是演示数据。本轮只出设计稿，没有改 `src`。具体令牌值等 T1 `refresh-plan.md` 出来后再对齐。

三个方向用同一份结构：侧栏（工作区、搜索、按项目分组的会话），加上主区（面包屑和分支、会话标签、工具），再加上终端区（状态条和输出）。和现状相比，三个方向都做了这些结构改进：

- 会话行显示两行：名称一行，Agent 和状态一行；待确认用文字徽标表示，不只靠颜色。
- 搜索入口常驻在侧栏顶部，并显示 ⌘K。
- 工具栏显示项目、分支和会话标签，替换掉现在孤立的项目选择器和标题行。
- 终端状态条集中显示运行状态、路径、模型和上下文这些元信息。

## A · 石墨 Graphite+（现行方案的精修版）

参考 Zed、Warp 的安静感。

- **配色：** 保留现行的石墨色和 sage 绿（`#171a19` / `#b2d5b6`），把灰阶拉开到 4 档，辅助文字单独设一档 `--ink-3`。
- **字体：** Harmony 13px 用于界面，JetBrains Mono 13.5/1.65 用于终端。
- **密度：** 中等，会话行高 44。
- **质感：** 一块平面，靠 1px 分隔线分区，选中状态用 2px 绿色竖条或下划线表示，没有阴影。
- **取舍：** 迁移成本最低，大部分改动只是替换令牌。缺点是和现状的差别不明显，“高级感”的提升有限，绿色强调色在暗色下也偏灰。

## B · 曜石 Obsidian（推荐）

参考 Linear、Raycast、Arc。

- **配色：** 暗色用冷中性的近黑（`#0c0d10`）做底，内容面用 `#131418`。强调色是一个低饱和的靛蓝 `#8b93ff`（亮色下是 `#4f55d9`），和现行的蓝色品牌一脉相承。状态色单独成一组。
- **字体：** 和 A 一样；标题和选中项用 500 字重，不依赖 600 以上的字重。
- **密度：** 中等。
- **质感：** 侧栏和窗口底色融为一体，内容区是一块 inset 8px、圆角 12px 的浮起面板，用 1px 内描边、顶部高光和大范围柔和阴影做出层次。边框统一用半透明的白或黑，所以在任何底色上都协调。
- **取舍：** 层次最清楚，“终端是主角”的结构一眼就能看出来，最接近用户说的“高级感、专业感”。代价有两点：
  - 浮起面板需要配合窗口质感（T2 的 macOS vibrancy、Windows Mica）才能完全出效果；
  - 终端背景要和内容面对齐，所以 `xtermTheme.ts` 的 background 必须一起改。

## C · 纸墨 Ink（单色排版方向）

参考编辑器和排版类工具。

- **配色：** 几乎单色，暖墨色 `#0f0f0e` 配纸白 `#fbfaf6`，“强调色”就是正文色本身；只有状态（运行、待确认、错误）有颜色。
- **字体：** 分组标题用等宽大写和字距，加强“工具感”。
- **密度：** 最高，行高 36，会话副标题隐藏。
- **质感：** 只用发丝线，圆角 3–4px，选中状态用下划线和 2px 黑条表示。
- **取舍：** 风格最鲜明，亮色版尤其克制、耐看。但信息密度和层次全靠排版，长时间多会话时状态辨识度最弱；隐藏副标题也和“先看到在做什么”这一目标冲突。适合作为一个可选主题，不建议作为默认。

## 推荐

默认方向用 **B 曜石**，同时把 A 里“2px 竖条标出选中会话”的轨道母题吸收进来，保住 design-spec 里“会话轨道”的识别性。C 可以以后作为一个可选主题。

落地需要和其他任务对齐：

- **T1：** 用 B 的这几组令牌作为 refresh-plan 的取值起点：中性阶 backdrop、content、raised、hover、active、line、ink×3；accent 和 accent-bg；状态色组；圆角 6/8/12；阴影 shadow 一档；动效沿用 120–140ms 和 `cubic-bezier(.2,0,0,1)`。
- **T2：** 侧栏和底色一体的效果，在 macOS 上需要 sidebar vibrancy，Windows 上需要 Mica 或纯色兜底。
- **终端：** `xtermTheme.ts` 的 background 要等于新的 content 色。另外 ANSI 蓝和强调靛蓝要拉开，避免撞色。

所有组合都实测过对比度：ink-2 对各自背景 ≥5.9:1；最弱一档 `--ink-3` 对内容面和侧栏都 ≥4.7:1（初稿有 3.2–4.2 的几档，已调）。终端的 ANSI 色板还没纳入测算，落地时要随 xtermTheme 一起复核。
