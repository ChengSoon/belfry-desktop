# CM-12 命名工作区与布局恢复

目标：保存命名工作区的会话集合、分屏方向/比例和焦点；支持创建、重命名、切换、会话迁移及重启恢复。
边界：工作区切换只改变可见会话与布局，不重建终端组件。现有全量会话存档继续保存进程启动参数；真实进程跨退出保活仍属于 CM-06。

## 设计

- 新增独立、版本化的工作区集合存档；旧 `belfry.workspace.v1` 不改格式。首次使用将原有会话纳入“默认工作区”。
- 每个会话仅归属一个命名工作区；新会话加入当前工作区，关闭后清理引用；切换保存各自焦点和布局。
- 分屏树改为由工作区集合提供；所有 TerminalPane 继续以原 ID、原 React 位置挂载，只调整坐标和可见性。
- 侧栏展示当前工作区的会话，Quick Open 激活其他工作区会话时切到其归属；快捷键 1–9 仅对应当前侧栏。
- 空工作区显示现有新建 Shell 入口；创建/切换不隐式启动新会话，不复制已有会话进程。
- 存档校验限制大小、工作区数量、名称、布局深度、比例和重复叶子；缺失会话引用与修复结果可见。
- 对启动失败且目录失效的会话提供路径修复；保留原 tab ID 和历史会话 ID，修复不得重启仍在运行的会话。
- 保存失败显示未保存状态；保留当前内存布局与终端运行，不伪装为重启可恢复。

## 2026-09-12 界面方向调整

用户要求主工作台更简洁、有设计感，减少混杂信息。此次沿用已有字体与主题，统一为克制的桌面工具界面：

- 工作区名称作为单一管理入口，新建、重命名、迁移、修复及存档详情按需展开。
- 顶部使用真实的弹性工具栏，常驻搜索、文件审查和更多；协作、插件、快捷指令与主题切换进入更多。
- 常态仅显示项目名，完整路径保留在悬浮提示和项目选择器中；长名称截断，不能与工具重叠。
- 单项目省去侧栏重复分组标题，单窗格减少边框，统一留白、按钮尺寸和焦点反馈。
- 验证亮暗主题、窄舞台、弹层键盘操作、空工作区可操作，并确认终端挂载与原功能入口保留。
