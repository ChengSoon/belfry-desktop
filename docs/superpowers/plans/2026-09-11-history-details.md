# CM-09 历史对话详情与代码变更回看

目标：在现有历史列表内打开只读详情，查看用户/助手消息、工具调用和来自原始日志的文件修改；按修改记录返回对应消息。
边界：只读取已选择的原生会话；恢复会话继续使用原 session ID；不读取当前项目文件来补造历史版本，不改写 CLI 日志。

## 设计

- 复用历史面板，列表增加详情入口；详情内保留继续会话和返回列表，不丢失列表筛选与收藏状态。
- Codex 读取 response_item 的消息、函数/自定义工具调用及结果；Claude 读取 user/assistant 内容块和工具记录。
- 编辑记录只展示日志中的 patch、Edit 的旧/新片段和 Write 的写入内容；缺少原始内容、执行结果未知或失败时明确标注。
- 同文件的每次修改保留独立事件、顺序、时间和来源消息；不合并为当前磁盘 Diff。
- 以 Agent + 原生 ID 解析日志，拒绝越界路径和外部符号链接，忽略其他会话及子会话内容。
- 分段读取和展示；后端读取量、单行、消息/工具文本、内存及活动读取器均有界。坏行和截断可见，旧响应不进入新会话。
- 日志被替换或截断时提示重新打开，避免把不同版本的页拼接；正常续写由显式刷新读取。
- 新增私有详情契约和模块，不修改共享 Agent 协议，不新增依赖。
