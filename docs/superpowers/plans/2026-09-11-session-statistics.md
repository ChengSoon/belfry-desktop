# CM-05 当前会话统计

目标：在当前终端内按原生会话身份查看四类 Token、模型、工具调用与更新时间，日志续写后自动刷新。
边界：只读取本地 CLI 会话日志；不请求模型 API，不读取凭据，不改写原始日志。费用留给 CM-10。

## 设计与风险

- 身份来自 CM-01 Hook 或显式恢复的原生 session ID；缓存以 Agent 和 session ID 组合隔离。
- 日志路径必须在当前 CLI 配置目录下，并校验原生日志身份。支持 `CODEX_HOME` 和 `CLAUDE_CONFIG_DIR`。
- 保留每个文件的增量游标，完整 JSONL 行才参与统计；分批处理并显示扫描进度。
- 检测截断、替换与已读内容变更时重建会话缓存；resume 多分片按事件身份去重。
- Codex 按累计用量差值计数，输入扣除缓存读；Claude 同一消息的流式重复记录取已知最大值。
- 缺失 Token 字段显示“不可用”，不伪装成 0；reasoning token 不重复计入输出。
- 工具只统计唯一的调用 ID，忽略结果记录和子会话；没有工具 ID 的日志明确标注数据不完整。
- 字节预算、单行上限与缓存上限保证坏日志和大日志不阻塞终端。
- 当前终端状态条增加“会话统计”入口；只在可见面板打开时轮询，切换会话后丢弃旧请求结果。
