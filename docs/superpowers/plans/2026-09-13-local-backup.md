# CM-13 本地备份与选择性恢复

目标：导出有版本的本地 JSON 包，预览工作区/外观域，选择性恢复并可撤回。

## 设计与边界

- 工作区包含稳定会话目标、最近项目、命名分组与布局；排除终端输出、标题推断、启动脚本、环境变量、Provider、Hook 和插件私有数据。
- 外观覆盖主题、系统字体/字号与背景显示参数；字体和壁纸文件不随包复制，导入保留本机资源关联。
- 仅系统文件选择窗口读写用户选中的包；有界读取、版本和字段校验，不允许包指定本机写入路径或任意存储键。
- 恢复安排在下次启动、各 Provider/工作区加载前执行。当前进程继续运行，退出前仍可取消安排。
- 启动时先保存选中域原始快照，写后逐项回读；中途失败回滚，异常退出留下事务可在下一次启动恢复。
- 最近一次成功恢复可安排撤回；仅作用原选中域，未选域不变。显式预览说明恢复工作区会按已有恢复规则启动会话。
- 不新增依赖，不自动重启应用，不接触真实凭据；使用内存 Storage 故障注入和临时包做验证。
