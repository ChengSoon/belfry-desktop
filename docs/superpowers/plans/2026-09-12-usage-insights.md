# CM-10 用量趋势、费用与下钻

目标：在现有用量面板展示每日趋势、日期/项目下钻和可追溯费用估算，同时减少卡片与常驻说明。
边界：只读本机 Codex/Claude 日志；不代理请求，不读取凭据，不把费用估算当作服务商账单。

## 设计

- 新增独立 analytics 查询，复用现有解析、Codex 累计差值与 Claude 去重；旧 usage_report 保持兼容。
- Codex 恢复分片共用累计基线；同一请求输入未变化的流式快照先合并，按最后一次用量变化时间归属日期。无法可靠分配的回溯修正明确报错，不生成虚高估算。
- Claude 同一消息后续补写的用量按字段增量合并；两家 CLI 均遵循自定义日志根。
- 按 UTC 自然日、原始模型名、Agent 与项目聚合。报告返回同一批桶，所有图表/列表/合计由它们派生。
- 近 7/30 天包含今天，边界为 UTC 零点；全部范围中的无日期记录单独列出，不强行分配到某一天。
- 按项目、日期交叉下钻；全历史图表以 30 天分页，保留逐日语义。额度与日志扫描来源继续可查看。
- 独立版本化价格表支持精确模型名/显式别名、项目覆盖、生效日期、USD/CNY 与来源说明。
- 初始价格表为空，避免擅自将官方费率套到中转请求。未知模型/无可用价格/无日期记录显示未配置或无法估算，不显示 0 元。
- 四类 Token 分别计价；不同货币分别汇总，不隐式换汇。只在最终显示时舍入。
- 价格保存显式执行；无效/过新存档保留原文；并发修改报错，不自动覆盖其他窗口。
- 主视图为总量、费用和小型每日图表；模型/项目明细、价格编辑与统计口径按需展开。

## 风险与验证

风险集中在日期边界、重复计费、精确模型匹配、项目归属、旧响应污染及持久化错误。
核心行为采用 TDD，覆盖 UTC 零点/显式时区、日桶与总计一致、无日期记录、跨模型/项目隔离、价格版本和缓存费用。
运行完整前端/Rust 回归、TypeScript、独立 QA 构建与差异自审；桌面恢复后验收亮暗主题、窄面板、下钻与价格重启保存。
