# 界面控件统一与简化

目标：应用内下拉、日期、数值、勾选、滑杆和折叠内容均使用一致的自定义控件；保留现有功能与数据语义。

视觉方向：克制的工具界面。使用现有字体和主题色，统一轻边框、圆角、留白与焦点样式；减少重复装饰，仅在选中和聚焦时强调。

- [x] 最终回归、构建及 macOS 桌面键盘/鼠标/主题验证。

## 边界与验收

- 不扩展 CM 功能，不修改持久化格式、依赖或后台协议。
- 日期值仍为 YYYY-MM-DD，价格按 UTC；手工输入与日历选择均可用。
- 可输入下拉保留自由输入；数值草稿不因空值变成 0。
- Portal 归属可追踪，内层 Esc 不关闭外层；禁用项不可选，支持键盘与输入法。
- 折叠保留草稿；表单错误在应用中展示，不依赖原生校验气泡。
- 应用内控件统一自绘；文件导入仍使用系统文件选择窗口，保留现有授权方式。
- 新共享行为做定向测试，再运行前端全量测试与构建。通过真实 QA 窗口验证布局、滚动、焦点和亮暗主题。

## 风险

自定义控件易破坏嵌套弹层、焦点顺序和已有宽度约束，迁移时同步检查 CSS 与语义。保留工作树已有改动及 Windows 安装修复。
