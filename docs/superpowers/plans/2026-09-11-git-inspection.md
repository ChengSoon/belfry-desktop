# CM-03 Git 状态与只读 Diff 实施计划

目标：在现有文件预览入口提供 Git 视图，展示当前仓库分支、暂存区、工作区、未跟踪文件和冲突；支持按文件阅读 hunk 并打开现有文件预览。

边界：本项仅读取 Git，不执行 add、commit、checkout、reset、merge 或远程操作。使用现有 Git 可执行程序与 React/Tauri，不增加依赖。

设计：

- Rust 使用 `status --porcelain=v2 -z --branch` 获取稳定的结构化数据，识别重命名、删除、中文及含空格路径。
- 命令以参数数组运行，禁用可选索引锁、fsmonitor、外部 diff 和 textconv；限制执行时间与输出大小。
- Git 根目录由 Git 自己解析；文件预览使用实际仓库根，处理项目位于仓库子目录的情况。
- 已暂存与未暂存分别查询 Diff；未跟踪文件按新增文件展示；二进制、超大 Diff、无差异和非 Git 目录都有可见状态。
- UI 复用右侧文件面板，按视图切换；后台轮询有过期响应隔离，切换项目不展示旧仓库结果。
- 新模块保持文件不超过 300 行、函数不超过 50 行；现有入口只做最小接线。
