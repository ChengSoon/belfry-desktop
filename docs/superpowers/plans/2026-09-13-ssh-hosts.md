# CM-11 SSH 主机与远程目录

目标：保存非敏感主机档案与分组，导入 OpenSSH 明确别名，显式诊断/浏览远端目录后启动 SSH。
界面沿用 frontend-design 的简洁方向：SSH 弹窗内选择主机，认证与存档按需展开。

## 边界

- 主机存档独立版本化，只保存名称、分组、host/user/port/remotePath，不接收密码或私钥。
- 复用系统 OpenSSH 的别名、密钥、ProxyJump；静态读取配置不执行 Match/ProxyCommand。
- 诊断和目录浏览使用 BatchMode、严格主机指纹校验、有限超时与可取消的独立进程组。
- 远端目录仅接受绝对 POSIX 路径，安全引用；不写入本机 project.rootPath，不参与本机文件/Git/历史扫描。
- 密码仍只通过现有系统凭据库和交互终端处理。浏览不接受密码，不自动接触用户真实远端。
- 不新增依赖；共享 SSH 目标增加可选字段，旧存档仍可读取。
