# CM-16 命令与 Prompt 收藏插件

目标：以独立、可选 PI 插件提供全局/当前项目收藏、分类搜索、变量预览与编辑后复制。
沿用 frontend-design：两栏轻量布局，项目与数量为次级信息，编辑和预览按需出现。

## 设计

- 插件位于 `examples/plugins/command-library`，提供可安装 `.piplug`，不增加常驻核心入口。
- 权限仅面板与写剪贴板。使用宿主 workspace 上下文和插件自身数据目录；不请求终端执行、网络或凭据权限。
- 全局模板可复用，项目模板按宿主路径隔离；后端再次验证作用范围，面板不能伪造其他项目。
- 变量支持项目名/原始路径与显式 POSIX/PowerShell 引用。预览可编辑，复制前再核对项目上下文。
- 版本化、有界存档，保存前比较版本摘要，原子写入；归档可恢复，损坏文件不覆盖。
- 没有自动投递或执行。插件禁用后核心工作台维持原有行为。
