# CM-07 / CM-08 Worktree 任务工作流

目标：从当前本地 Git 项目创建独立任务分支/目录，打开为会话；审查后显式提交、合并、清理。

## 边界与风险

- 入口位于 Git 面板，主工作台不增加常驻工具。创建表单、任务列表和收尾向导按需打开。
- 只管理 Belfry 创建并登记的 Worktree；持久化独立于仓库，不改根配置或 `.gitignore`。
- 写操作必须先预览获得短期一次性票据；执行再次比较 HEAD、分支、文件快照及归属，变化后要求重新预览。
- 提交范围为所选任务全部未忽略变更，显示文件和 Diff；空差异不提交。Git 失败时保留文件和暂存状态，不强制重置。
- 合并目标必须为同仓库已检出的分支；源与目标均需干净，无已有合并/变基，目标有改动即拦截。冲突停下并列出文件，不自动丢弃或继续提交。
- 清理只删除已合并、干净、没有忽略文件且无 Belfry 运行中会话的受管目录；使用 Git 非强制 remove，保留分支。
- 不自动执行依赖初始化或 Git Hook；依赖建议为可复制文本。所有测试在专用临时仓库中运行。
- 在本进程内串行写入；外部 Git 并发在每步重新校验，遇到状态变化或锁冲突保留成果并报错。
