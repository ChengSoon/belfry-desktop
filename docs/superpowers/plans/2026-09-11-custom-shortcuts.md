# CM-15 快捷键自定义

目标：为现有宿主动作提供录制、重绑定、停用、逐项和整体恢复默认值，并同步快捷键速查及按钮提示。
边界：保留 macOS 的 Command、Windows/Linux 的 Ctrl+Shift 作用域，给 CLI 原生 Ctrl 组合键和系统操作让出空间。
不新增命令执行动作，不修改插件设置或操作系统全局热键。

## 设计

- 统一现有动作目录；第 1–9 个会话分别可编辑，以物理 `KeyboardEvent.code` 匹配。
- 两个平台分别保存覆盖值，`null` 表示停用；旧安装没有存档时完整保留默认行为，包括 / 与 ? 速查入口。
- 拒绝重复映射及已知的复制、粘贴、查找、刷新、退出、最小化等保留键位。
- 已启用插件的快捷键参与冲突提示；宿主运行时与插件使用同一份当前映射判断优先级。
- 录制时宿主和插件快捷键均不触发；Esc 取消、Tab 离开，中文组字、长按和 AltGr 不录入或触发。
- 先录制和预览，再显式保存；存储失败显示错误，不伪装成保存成功。
- 配置更新后同窗口即时生效，重启后保留；按钮提示和快捷键速查同步当前映射。
- 不改写 root 配置、不新增依赖；沿用现有设置界面样式。
