# CM-14 项目收藏与启动配置

目标：长期收藏不受最近 6 项限制；支持分组、失效目录检查/修复和项目级 Shell、启动命令、非敏感环境变量。
界面沿用 `frontend-design` 的克制方向：入口放在项目切换器，配置在独立管理弹窗按需展开。

## 设计与边界

- 新增独立版本化项目目录存档，以规范化路径识别项目；保留现有最近项目及工作区格式。
- 收藏与配置最多 200 项，名称/分组/命令/环境变量有界；写前检查并发变化，写后回读。
- 修复路径只更新收藏和未来启动配置，不重新绑定运行中会话；重复目标路径拒绝覆盖。
- 环境变量仅保存非敏感值；拒绝凭据类名称、私钥和保留的 CLI/协作/系统身份变量。
- 新建本地会话取得配置快照；SSH 不应用本地启动配置。显式选择 Shell 优先于项目默认。
- 启动命令仅对用户新建的 Shell 执行；恢复存档、切组、换肤和重新挂载不重放命令。
- 启动命令在成功创建且仍有效的 PTY 上发送一次；若发送失败显示错误，不自动重试执行。
- 不自动读取或执行仓库脚本，不新增依赖，不操作用户 Git 或凭据。
