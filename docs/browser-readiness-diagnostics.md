# Browser fixture readiness diagnostics

The market and dropdown test fixtures now retain the first readiness error even if the later accessibility snapshot fails. `waitFor(view, expression)` keeps its existing signature, return value, in-page polling expression, 10-second page deadline and 20-second CDP deadline. Its error still includes the expression and available accessibility tree; `cause`, `code` and `browserRequest` identify the original failure, and `snapshotError` separately identifies a failed snapshot. The production browser engine and all original dropdown/market assertions are unchanged.

`marketUiFixture` adds diagnostics for its isolated test browser and Vite server. Reports go to `BELFRY_MARKET_UI_ARTIFACTS`, falling back to the existing CI `BELFRY_PANEL_ARTIFACTS`. Each fixture writes `market-ui-readiness/<pid>-<fixture-id>.json` and a separate `.browser.json`. The fixture ID, test name, browser ID, hashed frame/session/loader identities and `browserClockOffsetMs` connect both clocks and records. Failure data is saved before the subsequent snapshot; final reports include target, browser, server and temporary-directory cleanup. Either write can fail independently, with errors retained in memory and TAP diagnostics.

Reports distinguish fixture preparation, navigation, the original condition request, snapshot collection and cleanup. They retain bounded context/lifecycle events, per-request send/reply/error timing, Vite request/status/error records, root mount and document readiness observations, page exceptions and console messages. Failed resources have a separate bounded history so later successful requests cannot erase the failure. A page sample includes at most 4,096 characters of root markup and 12 button descriptions. Each event channel retains its first 32 and last 96 events; captures retain at most eight samples. Dropped counts and unavailable observations are explicit.

Content sampling is guarded inside the page by the fixture's exact local origin and the two known `market-page.html` / `dropdown-page.html` paths. Other pages produce only an out-of-scope marker. No response bodies, request bodies or CDP expressions/results are added to the request trace. The copied production `BrowserDiagnostics` snapshot remains content-free, with its existing hashed identities and restricted stderr classification. Diagnostic installation and the additional page/frame observations each have an independent one-second observation window; a failed channel cannot abort another channel or replace the test result. These windows do not change or retry any original page/CDP request.

The added five cases cover original-error preservation (old helper fails), independently failing capture/write/setup channels, resource failure with a genuinely missing control, navigation/context change plus content scope, and the asynchronous exception timeline. To run the focused checks from a prepared worktree:

```sh
pnpm install --frozen-lockfile
pnpm build
BELFRY_REQUIRE_BROWSER_TESTS=1 BELFRY_MARKET_UI_ARTIFACTS=/tmp/belfry-readiness-artifacts node --test --test-concurrency=1 scripts/plugin-tests/market-ui-diagnostics.case.mjs scripts/plugin-tests/dropdown-ui.case.mjs scripts/plugin-tests/market-ui.case.mjs src/components/lazy/testing/interaction-details.case.mjs src/components/lazy/testing/perf-interactions.case.mjs src/components/lazy/testing/production-panels.case.mjs
```

All 22 distinct focused cases have passed locally across the recorded runs. The first Node 24 run passed 18 and could not start four production cases because this new worktree lacked `dist/index.html`. After building, the five diagnostic cases and four production cases passed 9/9, with no skipped cases. The earlier Node 20 diagnostic/dropdown/market run passed 13/13. Original logs, the unsuccessful freezing hypothesis, per-fixture JSON and the source/CI evidence index are retained under `/tmp/belfry-t45-*`; the local acceptance index is `/tmp/belfry-t45-validation.json`. These results validate error preservation and diagnostics, not a fix for the undetermined natural CI causes.
