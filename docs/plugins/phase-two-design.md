# 第二阶段：协议、恢复与运行协调定案草稿

日期：2026-09-06。来源：开发任务 `52hp7pcc` 的具体提案与 D1 源码阅读。
状态：用户已明确批准“全部按你的设计来执行”，包含本设计列出的共享协议、持久化、入口及单 owner 限制。
本文对旧设计中的同名细节优先；不扩大 P0 功能范围。

## 1. 提案评审结论

采纳：插件子系统单 owner、独立存储、原始 JSON 文本快照、字符串 revision、
所有模板统一走 Recipe、完整 run 关联与永久撤销标记、原子替换后不确定结果单独处理。
不采纳前端重新序列化 manifest 再提交：这会丢失重复对象键，导致后端无法复验源文件。
不把原子 rename 等同于断电耐久，也不把磁盘已变化但响应失败当作“什么也没发生”。

D1 需求复核：version.ts 符合三元组与宿主预发布比较方向；catalog.ts 是已校验内容投影，
不能代替 manifest 验证；differences.ts 保留数组顺序与正文差异，适合贡献差异预览。
这只是源码与需求核对；不将开发报告的自动测试计为项目经理重新执行过的测试。

## 2. 生命周期状态

拆开四个维度，不用一个 enabled 布尔值表达所有问题：

| 维度 | 值 | 含义 |
| --- | --- | --- |
| owner | acquiring / owned / occupied / error | 进程是否拥有插件子系统 |
| store | loading / ready / read-only-error / reconciling | 受管数据是否可作为当前事实 |
| entry | enabled / disabled / incompatible / invalid | 单个插件的可用性 |
| operation | idle / inspecting / committing | 本地协调器是否允许新动作 |

运行允许条件：owned + ready + enabled + 无管理互斥 + 预览 revision 有效 + 目标有效。
启动不等插件扫描即可显示终端；owner 获取不得阻塞 UI 或 PTY。
occupied 页面只提供解释和重试，不展示来自上次缓存的可运行模板。
锁异常显示错误并允许重试；不能把权限失败误报成其他实例占用。
WebView reload 不释放进程锁；内存队列与关联重新建立，不恢复旧运行。
P0 只允许一个主窗口拥有插件运行协调器；新增窗口需另行接入同一协调器。

## 3. 交互详化

### 3.1 设置主视图

第一行“插件”，右侧“从文件安装”；说明“安装可复用的 Agent 指令与工作流”。
第二行搜索和状态筛选；列表行只放名称、简述、版本、来源、状态和启用开关。
列表点击进入详情，返回保持搜索和滚动位置；操作完成将焦点回到对应条目。
卸载后焦点落在下一条或导入按钮。错误信息与重试按钮放在发生错误的区域。
插件名称相同则同时展示 ID；author 旁标“作者提供”，不使用认证图标。

### 3.2 安装与替换预览

顶部显示文件名、插件身份、兼容状态；中部列模板与动作，允许逐项展开完整正文。
替换页面并列列出当前/新版本，贡献按新增、删除、变更分组。
除贡献差异外，另显示作者、名称、描述、兼容范围变化；不能以“模板无变化”掩盖来源变化。
仅增加 JSON 排版空白或重排 JSON 对象键不构成内容变更；步骤顺序与正文空白变化必须展示。
没有贡献差异但版本不同仍允许明确替换；同版本一律拒绝，保持首期规则。
确认按钮在明确显示“安装后/替换后需重新启用”后可用，取消不动磁盘。

### 3.3 运行预览

依次显示插件/版本 → 项目/会话 → 变量 → 展开后完整步骤 → 提交按钮。
一个模板只有一个启动路径；Quick Open、详情、Recipe 分组均打开相同预览。
表单不读写 Composer 草稿；变量只存本次预览内存，关闭后清空。
插件、项目或目标身份变化时失效，提示“内容或目标已变化，请重新预览”。
变量值先验证控制字符，再替换一次，最后按 UTF-8 字节验证每步及整轮上限。
用户输入中的 `{{text}}` 作为普通文本，不再次替换；禁止用剩余占位符扫描误判该输入未填写。

### 3.4 管理确认

禁用示例：“禁用‘代码审查助手’？将中止此插件尚未发送的步骤。已发送内容无法撤回。”
有准确队列计数时展示待发步骤数；in-flight 单独称为“已交给终端、送达尚未确认”，不归入可撤回数。
未能准确计数时只显示关联运行数和上述说明，不编造待发数字。
取消后不撤销；确认后先同步取得管理门禁；可信目录下同状态请求不撤销，真实变更撤销关联后再提交。
重新启用只能开始新轮次；已撤销轮次永远不能借重新启用恢复重试。

## 4. 传输与存储字段草案

所有时间戳为有限整数 epoch 毫秒；不得用浮点 NaN/Infinity 或字符串时间混用。
revision 为十进制 u64 字符串，初始 `"0"`；无前导零、正号或空白，溢出拒绝写入并报告错误。
每次成功变更加 1；同状态启用/禁用可返回 no-change，不递增，不撤销当前轮次。
后端先检查 owner、完整磁盘内容、requestEpoch 与 expectedRevision，再判同状态，最后 checked_add。
no-change 不写时间戳/诊断等持久字段；revision 达上限仍允许 no-change。
TS 以规范字符串比较相等，不转 Number；确需大小比较用 BigInt。
全局 revision 改变使所有已打开运行/安装预览失效；首期接受重新预览的成本，避免复杂局部修订。

受管根字段：storeSchemaVersion、revision、plugins。
插件条目字段：currentManifest、enabled、installedAt、updatedAt、sourceFileName、
可选 previousManifest、diagnostics。回退后 sourceFileName 置为 null并显示“上一版本快照”，
避免错误显示新版本文件名；installedAt 保留，updatedAt 更新。
sourceFileName 是展示元数据，缺失统一为 null；提供时 ≤ 255 码点，无控制字符或路径分隔符。
previousManifest 不保留 enabled，恢复后一律 disabled；回退成功清槽。

inspect 返回 rawManifestText、已校验视图、文件名、baseRevision、差异；
install/replace 提交同一 rawManifestText、清洗后的 sourceFileName、expectedRevision 和 requestEpoch，
后端重新完整验证。重复键必须在 JSON Value/Map 构造前检测，registry/回退内容也严格解析。
拒绝末尾多余 JSON；原文解析前限额不等于消除 Tauri 接收字符串之前的内存分配。
原文仅在本次预览内存保留；持久化的是后端验证后的结构，不要求保存源文件排版。
通过 raw 字符串也不能替代有界 IPC 输入检查；后端在解析前检查其 UTF-8 字节数。
重复键检查包括 JSON 转义后相同键（例如 id 与 \u0069d），作用于所有嵌套对象。

## 5. 命令结果与不确定提交

管理命令采用结果封套草案：outcome、可选 registry、可选 issue。
outcome 可为 applied、no-change、not-applied、unknown；issue 包含 code、message、fieldPath?。
owner 状态查询和显式 acquire_owner 不要求已持锁；其他插件业务命令必须 owned。
新增错误分类：OWNER_UNAVAILABLE、OWNER_IO、REVISION_EXHAUSTED、COMMIT_UNCERTAIN。
具体 Rust/TS 类型仍待实施边界批准后生成；此处是产品语义规范。

| 故障位置 | 返回语义 | UI 与后续动作 |
| --- | --- | --- |
| 参数校验/写临时文件/rename 前且库可信 | not-applied，原 registry | 保留原版本/启停，允许重新发起操作 |
| 发现库损坏/消失/外改 | not-applied，无可信 registry | 统一失效撤销，进入故障态或恢复屏障 |
| rename 成功且同步完成 | applied，新 registry | 更新列表并关闭确认页 |
| rename 后同步报错，读回匹配新状态 | applied + 耐久性提示 | 显示实际新版本，不自动重试，不承诺断电安全 |
| rename 后状态无法读回或无法判定 | unknown，无可信 registry | 进入 reconciling，停用所有插件入口，提供重新读取 |
| IPC 拒绝或超时 | 客户端视为 unknown | 执行后端恢复屏障，不能普通读取后直接恢复或自动重发 |

管理 IPC 超时建议 15 秒，作为可测试常量；超时不代表后端取消。
超时前 pending 显示提交中；超时或 Promise 拒绝才进入 unknown。
新增 plugins_reconcile：在同一后端写锁内推进内存 requestEpoch，再读盘返回 epoch/registry。
mutation 实际取得写锁后检查 epoch；旧 epoch 拒绝写入。已持锁提交先完成，屏障随后读取；
未开始或晚到的旧请求被屏障的新 epoch 作废。WebView 初始化/reload 同样经过屏障。
非 owner 不得 reconcile；屏障失败维持不可运行态。epoch 为进程内 u64 十进制字符串，溢出拒绝继续。
前端用 operation token 与 catalog generation 丢弃迟到响应；恢复调用串行，共用同一在途屏障。
不新增持久化操作日志。屏障成功后以磁盘为准；如果不能证明上次具体操作已生效，提示当前状态并要求重新预览，
不凭插件名字或 UI 缓存拼出“更新成功”。expectedRevision 防止旧请求再次覆盖。
任何阶段已取消的运行保持 revoked；重新读取或失败恢复都不能自动入队。
统一失效规则：unknown、已检测到库损坏/消失/外改、失去 owner 时，
同步 ref 关闭门禁 → 全部插件关联标 revoked → 无 await 遍历 abortRun → 再发布 UI/异步恢复。
同步递增 catalog generation，让同 revision 外改前的旧预览也失效。
保守中止全部插件轮次待发；no-change 响应丢失也遵守 unknown 撤销优先。
普通 Prompt/Recipe 不受影响。诊断只写有限管理元数据；故障期诊断可留内存，不递归写坏库。

## 6. 损坏与外部修改

首次不存在文件可显示空库；本 owner 生命周期内曾成功读取后文件消失属于异常。
跨应用重启不承诺识别被删的旧库；当前无可靠持久标记，不能用 owner.lock 是否存在猜测。
根结构损坏、未来 schema、坏 entry 都保留原件；read-only-error 只允许诊断与重新读取。
此时不要显示可用的启停/卸载按钮；旧文档“故障可卸载”仅适用于根库可安全写入的单插件问题。
P0 不自动修复、导出或删除损坏库；用户恢复文件后重新读取，恢复流程不操作其他用户目录。
OS owner 锁协调 Belfry 进程，不防同一用户外部软件改文件；不声明防篡改保证。
每次持久化重读并校验；不一致则失效所有预览并重新加载，不盲信内存 revision。
相同 revision 下外部内容变化应按意外修改处理，不能覆盖；开发采用前后内容比较即可，
不要求为此新增哈希依赖。加载后未发生管理操作时不承诺实时监视外部编辑。

## 7. 运行撤销不变量

每个插件 runId 在本次 WebView 会话保留来源与 revoked；上限 1000，与历史面板 8 条无关。
所有 mutation 含启用/禁用/no-change 同一时刻仅允许一个管理提交（P0 全局串行）。
进入确认对话框不立即停任务；点击确认才同步置管理门禁，真实变更才撤销受影响轮次。
运行校验至 startRun 返回并登记关联不得 await；权威是同步协调器，不是下一帧 React state。
所有旧运行重试、快捷动作、已开预览必须经过同一协调器，不能直接绑定底层 resendStep。
插件命名空间历史若来源关联丢失则拒绝重试；按钮与回调都必须检查。
原始模板无编辑入口；用户副本脱离关联，但复制操作须同样检查 owner/模板有效性和用户库上限。
退出占用进程不移交内存状态；接管实例只获得插件定义和启停状态。

## 10. 人工验收走查脚本

演示数据：一个含单步 Prompt 与两步 Recipe 的 v1.0.0 插件、修改正文的 v1.1.0、
一个转义重复键非法文件；两个同项目 Agent 会话，其中一个忙碌。
使用测试临时插件根目录与专用测试会话；正式功能无须向普通用户展示测试目录开关。

1. 启动主实例，安装 v1.0.0，确认列表默认禁用，终端无新增输入。
2. 启用，从 Quick Open 打开模板，填写变量，检查完整预览后向忙碌会话入队。
3. 中途禁用，确认未发步骤中止；其他手工 Prompt 仍保留，旧运行重试不可用。
4. 重新启用并创建新运行，确认旧轮次不复活；复制模板后修改用户副本。
5. 导入 v1.1.0，审阅差异并替换；确认默认禁用且用户副本保持修改。
6. 回退，确认版本与来源标签正确；关闭重启，确认无运行重放。
7. 同时启动第二实例，确认只有插件功能被占用；退出第一实例，显式重试接管。
8. 导入非法文件，确认字段错误且当前插件不变；完成卸载，确认用户副本与源文件保留。

故障注入由开发测试单独覆盖，禁止为演示损坏真实用户数据：rename 前后失败、
响应丢失、owner 崩溃、PTY 子进程存活、同 revision 外改及超过 8 条历史撤销。
交付证据至少包含每个平台的环境与结果、关键状态截图、自动测试命令和未验证项。
无 Windows 环境时设计可完成，功能验收仍明确保留 Windows 未验证项。
