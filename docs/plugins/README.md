## 核心决策

> 以下决策已经被新方向取代，仅作为历史记录。新代码不得继续按模板插件扩展。

- 产品是 Belfry 桌面应用的插件系统，不是 Codex 插件包，也不是 Tauri 原生插件管理器。
- P0 是本地、声明式、用户手动触发的插件：Prompt 模板、Recipe 模板、Quick Open 动作。
- P0 使用单个 UTF-8 JSON 文件导入，内容内联；免去解压、资源寻址和执行环境依赖。
- 宿主负责渲染和动作执行；插件文件不包含可执行代码、HTML、外部资源或生命周期脚本。
- 安装范围为本机当前 OS 用户；运行必须明确绑定一个 Belfry Agent 会话。
- 插件原始定义与用户 Recipe 分离；用户可复制模板为自己的 Recipe。
- 安装与更新都默认禁用；更新保留上一个有效版本供回退。
- MVP 不改现有 PromptOrigin、Recipe、AgentKind；来源信息优先保留在插件侧关联表。
- 不把“全部指令已送达”解释成 Agent 完成工作；不伪造任务成功状态。
- README 排除插件市场仍然成立；市场单独决策，首期不建设。
