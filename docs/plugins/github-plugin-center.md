# 独立 GitHub 插件中心

执行日期：2026-09-10。由主会话直接实现，保留现有插件移植目标。

## 目标与边界

用户要求拥有与 `vastsa/pi-desktop-plugins` 同类的独立插件中心。
本地项目：`../belfry-desktop-plugins`；公开仓库：`ChengSoon/belfry-desktop-plugins`。
参考固定版本：`9b68e43f89af6b033d50f63c31e2043fb49b86b4`，保留 MIT 来源说明。

包含插件源码、不可变 `.piplug` 发布包、PI 兼容 `catalog.json`、模板生成工具、
检查和发布脚本，以及沿用上游布局的首页、搜索、详情和开发文档。
网站改为静态构建，支持 GitHub Pages；客户端增加独立 Belfry GitHub 来源，
保留原 PI 来源和已安装插件的来源身份。尚未发布的地址不作为默认来源。

不恢复 Harness，不覆盖其他工作区改动，不委派。远程仓库创建、提交、推送及部署
均需有对应操作结果，不能把本地文件当作已经上线的市场。

## 风险与验证

- 包和目录摘要必须一致；同一版本不得换包，历史版本必须保留。
- 拒绝越界路径、符号链接、重复 JSON 字段和超限包；不虚构认证或下载量。
- 自动生成 manifest，作者无需手写才能开始；安装者直接导入包。
- 发布工具先做失败用例；网站构建后验证搜索、分类、语言、复制和真实下载。
- 主项目继续验证 Node 插件、Rust、前端及结构限制。新包和历史 UI 证据分开记录。

## 实现结果

独立目录包含 `plugins/`、`packages/`、`catalog.json`、`marketplace.json`、Python 制作工具、
Next.js 静态网站、发布测试及 GitHub Actions。初始插件为工作便笺、文本统计、代码审查指南。
模板支持基础面板、Agent 工具、Skill 包和完整示例；自动生成 manifest。

网站保留上游首页、搜索、分类、详情、权限、开发指南和中英文切换；调整为静态构建，
支持 GitHub Pages 子路径，包与目录随站点导出。客户端新增独立 `belfry` 来源，
默认仍为本地个人市场，原 PI 来源身份保持独立。

打包采用固定时间和排序的 ZIP Store。发布版本不可覆盖，写包使用同目录临时文件及
原子创建；重建目录保留历史与撤回标记，并检查源码、包及 SHA-256 一致性。
拒绝链接、越界、重复 JSON 键、大小写别名、Windows 保留名称和文件/目录冲突。

## 切换 GitHub 来源时的 404

用户已确认 404 出现在切换 Belfry GitHub 市场时。2026-09-10 实际请求目标 raw 目录返回
404，仓库仍未发布；PI GitHub 与镜像目录分别返回 200。此时不能把本地项目误认为线上市场。

客户端现先验证候选目录再保存来源，未发布时保留原市场，明确提示发布条件。旧设置可通过
「使用我的插件市场」恢复；目录 404 与包 404 分别诊断，不把旧来源的卡片显示在失效的新来源下。
已验证的同源缓存可离线选择；自有地址为空时允许先填写。

新增 8 项来源回归与 5 项前端加载回归通过；最终主项目 Vitest 572、Node 124、Rust 插件
61 项通过，独立 QA 已重建。详见 [移植执行记录](./pi-desktop-port.md)。
